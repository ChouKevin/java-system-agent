# java-system-agent 服務摘要

這個服務是一個 Slack AI 助理：使用者在 Slack 提及機器人並提出關於 Java 系統的業務問題後，服務會對已註冊的程式庫執行靜態呼叫鏈分析，再由兩層 LLM 流程把技術結果翻譯成業務語言回覆。

主要能力：

- 管理被分析的程式庫（下載、更新、切換版本），並在啟動時預先載入快取
- 依方法座標或 API 路徑產生呼叫鏈，附帶信心度與證據
- 在 Slack 討論串內維持多輪對話記憶，回覆以串流方式逐步送出

本 repo 同時是文件結構的示範對象：實際部署時可註冊多個程式庫，每個程式庫在 `knowledge/repos/{repoId}/` 各有一套業務文件
